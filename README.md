## Descripción del proyecto

Este proyecto consiste en el desarrollo de un programa en Python que permite generar contraseñas seguras de forma automática. El sistema solicita al usuario la longitud de la contraseña y permite seleccionar si desea incluir letras mayúsculas, letras minúsculas, números y caracteres especiales.

El proyecto responde a una necesidad actual relacionada con la seguridad digital, ya que muchas personas utilizan contraseñas débiles, repetidas o fáciles de adivinar en redes sociales, correos electrónicos, plataformas educativas y aplicaciones bancarias.

## Objetivo del sistema

Desarrollar un sistema que genere contraseñas seguras de manera rápida y sencilla, utilizando diferentes tipos de caracteres para mejorar la protección de la información personal del usuario.

## Funcionalidades del sistema

* Solicitar la longitud de la contraseña.
* Permitir incluir letras mayúsculas.
* Permitir incluir letras minúsculas.
* Permitir incluir números.
* Permitir incluir caracteres especiales.
* Validar que el usuario seleccione al menos una opción.
* Generar una contraseña aleatoria segura.
* Mostrar la contraseña generada en pantalla.
* Permitir generar una nueva contraseña.

## Cómo ejecutar el programa

1. Descargar o abrir el repositorio.
2. Ingresar a la carpeta `codigo`.
3. Abrir el archivo `generador_contrasenas.py`.
4. Ejecutar el programa en Python.
5. Ingresar la longitud de la contraseña.
6. Seleccionar los tipos de caracteres que se desean incluir.
7. Visualizar la contraseña segura generada.

Al generar contraseñas seguras, el programa ayuda a reducir riesgos como el robo de cuentas, la pérdida de información y el acceso no autorizado a datos personales.
